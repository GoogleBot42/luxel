Each row computes the range it owns rather than asking you to add up offsets, and reverse is shown where it is true: the second run's IN marker sits at the far end with its arrow pointing back. Output 2's blue is an identity colour, not a second accent — it means "this wire", and appears nowhere else in the UI.

What changed. The panel grid, the chain order and the wiring inside a panel are still described once, above; outputs only say where the one chain is cut. The picture carries that: panels are tinted by the output that drives them, each run is its own polyline with its own IN marker at the panel its wire plugs into, and the numbers stay the chain order so the table's panels 1–2 / panels 3–4 is something you can point at. Cutting anywhere but along the chain is not offered, which is why there is no per-panel output picker.
